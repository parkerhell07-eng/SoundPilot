# SoundPilot 🎵 — پلیر موسیقی آفلاین برای خودرو

اپلیکیشن بومی اندروید با **Kotlin + Jetpack Compose + Material 3** و موتور پخش **AndroidX Media3 ExoPlayer**؛ طراحی‌شده برای پخش موسیقی از گوشی به ضبط ماشین از طریق بلوتوث، با **اکولایزر واقعی متصل به نشست صوتی پلیر**.

> رابط کاربری کامل فارسی و راست‌چین • تم تیره • کاملاً آفلاین • بدون هیچ جمع‌آوری داده

---

## 📋 تغییرات نسخه ۱.۱.۰ (رفع باگ‌های گزارش‌شده از دستگاه واقعی)

### رفع باگ پخش — «لمس آهنگ هیچ واکنشی نداشت»
- اتصال به سرویس پخش حالا **timeout (۶ ثانیه) + تا ۴ تلاش مجدد خودکار با فاصله فزاینده** دارد؛
  قبلاً اگر اتصال اول ناموفق می‌شد، برنامه برای همیشه بی‌واکنش می‌ماند.
- **هیچ لمسی گم نمی‌شود**: اگر کاربر هنگام اتصال روی آهنگی بزند، درخواست در صف نگه داشته
  می‌شود و بلافاصله پس از برقراری اتصال اجرا می‌شود.
- **بنر وضعیت اتصال** بالای برنامه: اسپینر «در حال آماده‌سازی موتور پخش» یا دکمه «تلاش مجدد».
- **Snackbar سراسری خطاها** در همه صفحات (قبلاً خطاها فقط در صفحه پخش دیده می‌شدند و در
  صفحه کتابخانه شکست‌ها کاملاً بی‌صدا بودند).
- رفع یک باگ واقعی در «آهنگ بعدی» در انتهای صف (حالا با تکرار «همه» از ابتدا ادامه می‌دهد).

### رفع کندی برنامه
- **پایپ‌لاین جدید تصویر آلبوم**: URI قدیمی `content://media/external/audio/albumart` در
  اندروید ۱۰+ از کار افتاده بود و برای هر ردیف تلاش‌های ناموفق تکرار می‌شد. حالا کاور واقعی
  با `ContentResolver.loadThumbnail` (API 29+) و fallback کاور تعبیه‌شده فایل واکشی و در
  **کش دیسک + حافظه (LruCache)** ذخیره می‌شود — تصاویر درست نمایش داده می‌شوند و لیست روان است.
- `SubcomposeAsyncImage` سنگین با `AsyncImage` سبک جایگزین شد.
- **ایندکس جست‌وجوی نرمال‌شده**: نرمال‌سازی فارسی فقط یک‌بار برای کل کتابخانه انجام می‌شود
  (قبلاً روی هر حرف تایپ برای همه آهنگ‌ها regex اجرا می‌شد) + debounce تایپ.
- فیلتر/گروه‌بندی کتابخانه به **Dispatchers.Default** منتقل شد — ترد UI هرگز بلاک نمی‌شود.
- بازسازی صف پخش فقط با تغییر واقعی محتوا (امضای صف) — نه هر رخداد پلیر.

### ارتقاهای دیگر
- تصویر آلبوم واقعی در اعلان رسانه، صف پخش، مینی‌پلیر و صفحه پلیر
- نمایش کاور در اعلان قفل‌صفحه با نسخه ۱.۱.۰
- versionCode → 2، versionName → 1.1.0

## ✨ امکانات

### پلیر
- شناسایی خودکار موسیقی محلی از **MediaStore** (نمایش عنوان، خواننده، آلبوم، مدت و تصویر آلبوم)
- جست‌وجوی هوشمند فارسی (نرمال‌سازی «ي/ی»، «ك/ک»، نیم‌فاصله) و مرتب‌سازی (عنوان، خواننده، آلبوم، مدت، جدیدترین)
- تب‌های **آهنگ‌ها / آلبوم‌ها / خواننده‌ها / علاقه‌مندی‌ها** + صفحات جزئیات
- صف پخش کامل (پخش بعدی، افزودن به صف، پرش، حذف) با شافل و تکرار (همه/تکی)
- علاقه‌مندی‌ها با ذخیره‌سازی دائمی (DataStore)
- **پخش پایدار پس‌زمینه** با `MediaSessionService`، اعلان رسانه و کنترل از صفحه قفل
- پشتیبانی از دکمه‌های رسانه بلوتوث/فرمان ماشین (AVRCP) و مدیریت خودکار قطع/وصل
- مدیریت فوکوس صوتی (پاز هنگام تماس/ناوبری)، `handleAudioBecomingNoisy` (پاز هنگام قطع هدفون)
- ریکاوری خودکار از خطا: فایل خراب/حذف‌شده → پرش به آهنگ بعدی؛ پیام خطای فارسی به کاربر
- **بازیابی آخرین پخش** (صف + محل توقف) پس از باز شدن دوباره برنامه

### پردازش واقعی صدا
- اکولایزر واقعی `android.media.audiofx.Equalizer` متصل به `audioSessionId` خود ExoPlayer
- تشخیص خودکار **تعداد باند، محدوده فرکانسی و بازه دسی‌بلی واقعی دستگاه**
- پروفایل‌های **متعادل، بیس‌دار، وکال، شفافیت** به‌صورت منحنی فرکانسی — با هر تعداد باند درست اعمال می‌شوند
- حالت سفارشی با فیدر عمودی + گام نیم‌دسی‌بلی
- **BassBoost** و **Virtualizer** در صورت پشتیبانی دستگاه (نبودشان باعث کرش نمی‌شود)
- روشن/خاموش برای مقایسه صدا • ذخیره و بازیابی کامل تنظیمات
- سقف تقویت (+6dB پروفایل‌ها، +10dB دستی) برای جلوگیری از اعوجاج
- آزادسازی صحیح منابع صوتی هنگام تغییر نشست/نابودی سرویس

### تجربه کاربری
- **حالت خودرو**: دکمه‌های بسیار بزرگ و حداقل تعامل برای استفاده ایمن حین رانندگی
- RTL کامل، اعداد فارسی، حالت‌های بارگذاری/خالی/خطا/موفقیت
- نمایش **دستگاه خروجی فعلی** (بلوتوث/هدفون/بلندگو)
- تم تیره/روشن/سیستمی + دسترس‌پذیری (contentDescription فارسی، اهداف لمسی ≥۴۴dp)

## 🏗 معماری

```
app/src/main/java/com/soundpilot/app/
├── SoundPilotApplication.kt       # کانال اعلان + ServiceLocator
├── MainActivity.kt                # Compose + Edge-to-Edge + مجوزها
├── di/ServiceLocator.kt           # تزریق وابستگی سبک
├── domain/                        # مدل‌ها + منطق خالص کتابخانه (تست‌پذیر)
├── data/
│   ├── MediaStoreMusicRepository  # خواندن موسیقی محلی
│   ├── LibraryStore               # حافظه مشترک کتابخانه
│   └── SettingsRepository         # DataStore: تنظیمات/علاقه‌مندی/آخرین پخش
├── playback/
│   ├── PlaybackService            # MediaSessionService + ExoPlayer + ریکاوری خطا
│   ├── PlaybackErrorMapper        # کد خطا → پیام فارسی
│   └── MediaItems.kt              # Song → MediaItem
├── audio/
│   ├── AudioEffectsController     # Equalizer/BassBoost/Virtualizer واقعی
│   ├── AudioEffectsHub            # پل سرویس ↔ UI
│   ├── EqualizerMath              # منحنی‌ها و تبدیل dB↔mB (خالص)
│   └── EqualizerModels            # پروفایل‌ها و قابلیت‌ها
└── ui/                            # Compose: theme(تیره/RTL) + ۵ صفحه + ViewModel‌ها با StateFlow
```

وضعیت UI با **ViewModel + StateFlow** مدیریت می‌شود؛ لایه‌های UI / پخش / داده / صوت تفکیک شده‌اند.

## 📦 ساخت نسخه امضاشده برای انتشار

۱) ساخت کلید آپلود (فقط یک‌بار — کلید را گم نکنید؛ با Play App Signing لازم است):

```bash
keytool -genkeypair -v -keystore release.keystore -alias soundpilot \
  -keyalg RSA -keysize 2048 -validity 10000
```

۲) ساخت `keystore.properties` در ریشه پروژه (در `.gitignore` است و کامیت نمی‌شود):

```properties
storeFile=/abs/path/release.keystore
storePassword=****
keyAlias=soundpilot
keyPassword=****
```

۳) ساخت خروجی:

```bash
./gradlew :app:assembleRelease   # APK امضاشده
./gradlew :app:bundleRelease     # AAB (فرم موردنیاز Google Play)
# خروجی: app/build/outputs/bundle/release/app-release.aab
```
